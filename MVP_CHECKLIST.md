1. Откройте http://localhost:5173
2. Введите "Test Tournament"
3. Нажмите "Create Tournament"
4. Скопируйте ID турнира

## Отладка

### Если Display не обновляется:

1. **Откройте DevTools (F12)** → Console tab
2. Посмотрите, есть ли логи:
   ```
   [WebSocket] Connecting to: ws://localhost:5173/ws/tournaments/...
   [WebSocket] Connected
   [WebSocket] Message received: {...}
   ```

3. Если нет логов:
   - Проверьте, что сервер запущен: `curl http://localhost:3000/health`
   - Проверьте, что клиент запущен: http://localhost:5173 должен загрузиться
   - Смотрите Network tab в DevTools → найдите WS соединение

### Если сервер не запускается:

```bash
cd server
npm run test:run        # Проверить тесты
npm run dev             # Запустить сервер
```

### Если клиент не запускается:

```bash
cd client
npm run build           # Проверить build
npm run dev             # Запустить dev сервер
```
